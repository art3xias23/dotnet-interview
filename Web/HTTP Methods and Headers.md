**Common Methods:**

- `GET` — Retrieve data, safe.
    
- `POST` — Submit data, may change server state.
    
- `PUT` — Replace resource.
    
- `PATCH` — Partial update.
    
- `DELETE` — Remove resource.
    
- `HEAD` — Headers only.
    
- `OPTIONS` — Server-supported operations.
    
- `TRACE` — Echo request for diagnostics.
